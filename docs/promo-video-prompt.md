# dsh-pinned-sessions 宣传片制作提示词

40 秒竖屏之外的通用版：16:9 / 中文口播（年轻女声）+ 中英双语字幕 / 深色 UI + 描边动效。
成片路径为「真实录屏 + 动效包装 + AI 配音 + 字幕」，不调用视频生成模型。

## 一、可直接粘贴的制作提示词

```text
你是一位拿过国际广告奖的创意总监、导演兼文案。请独立完成一条 40 秒产品宣传片的全套创作文案，风格要求广告大片节奏、好莱坞级镜头语言、奥斯卡级导演思维。

【产品】
dsh-pinned-sessions：DeepSeek Harness（DSH）Web 侧栏的置顶插件。它把三类会话固定在侧栏工作区列表顶部——正在运行的、跑完但你还没点开的、当前打开的；并且允许从任意会话或工作区自己的「...」菜单里"全局置顶"。

【制作前必须先做的事实核对】
本插件没有外部媒体报道，权威来源只有两份，必须以其为准，不得编造任何未实现的功能：
1. 仓库 README 与 CHANGELOG：https://github.com/TianYa-DAO/dsh-pinned-sessions
2. 本文件第二节「事实底线」。
若某个视觉点子需要产品没有的行为，改成它支持的行为，不要虚构。

【影像语言】
1. 节奏按广告大片剪：40 秒分三次呼吸——0-8 秒痛点与压迫感，8-30 秒解决问题的高密度演示，30-40 秒收束升华。
2. 好莱坞级镜头语言：微距推近侧栏行；浅景深让背景工作区分组虚化；用侧栏圆角卡片形状做遮罩转场；关键动作 0.35 倍慢放，扫视段 1.6 倍加速。
3. 导演思维：第一帧就有信息量；每个镜头只讲一件事；把"状态圆点"作为全片视觉母题反复呼应；结尾给一句能被记住的话。
4. 画面全部来自真实产品录屏加动效包装，不拿非产品画面当证据。

【五轨同步】
画面、音乐、音效、口播、字幕五轨逐镜对齐。分镜表每镜必须写：起始时间码、时长、画面内容、镜头运动、字幕文字、音效、转场方式。旁白带时间码，且每一句口播都对应一个可见的画面动作。

【口播】
年轻女声，语速偏快、尾音干净、不过度煽情，中文。全片 95-110 字，宁可少字也不要赶。

【输出格式】
1. 一句话创意概念（不超过 25 字）。
2. 分镜表（Markdown 表格，8-10 镜）。
3. 旁白全文，带 [00:00.0] 时间码。
4. 音效表（时间点、音色、情绪）。
5. 字幕表（中英对照）。
6. 制作说明：不用视频模型时，如何用录屏、剪辑、动效实现上述镜头。

【约束】
独立完成，不参考任何本地已有素材或成品；不写产品没有的功能；不出现真人出镜与人脸；所有数字和说法以事实清单为准。
```

## 二、事实底线

只有下面这些是已实现并可上镜的行为，超出即视为虚构：

1. 置顶区三段式，顺序固定：全局置顶会话 → 进行中 / 待查看 / 当前打开 → 置顶工作区。
2. 会话行「...」菜单里有「全局置顶 / 取消全局置顶」，位置在归档之后。
3. 工作区名行「...」菜单里也有同名的「全局置顶」。
4. 状态圆点：运行中为蓝色呼吸点、待查看为绿点、当前打开为空心环。
5. 置顶去重：置顶区展开时，被置顶的会话不在状态分组里重复出现；点小箭头折叠「全局置顶」后，这些会话回到对应状态分组。
6. 置顶工作区在置顶区渲染成可展开的分组，里面的会话可直接点开；该工作区在下方列表里的原分组被隐藏；取消置顶后恢复。
7. 置顶区与下方工作区分组共用同一个滚动条，置顶项再多也能滚到底。
8. 设置 → 通用有「置顶会话区」开关；折叠状态会记住；侧栏收起成图标栏、切扁平列表、搜索时置顶区自动隐藏。
9. 发布状态：GitHub v0.2.0、npm 包同版本。
10. 不能出现的说法：智能排序、自动整理、多端同步、云备份、AI 摘要等未实现能力。

## 三、成片脚本包

### 1. 创意概念

一句话：一个点，把该在顶上的东西钉在顶上。

视觉母题是行首那个 7px 的状态圆点——全片从"看不见它"开始，以"它一直在那儿"收束。

### 3. 旁白全文（年轻女声，中文，约 105 字）

```text
[00:00.5] 二十七个会话，三个正在跑。
[00:03.0] 你确定，第一眼就能看见它们？
[00:06.0] 侧栏一长，正在跑的那个就被挤下去了。
[00:09.5] 点开会话右边的三个点，全局置顶。
[00:13.0] 运行中、待查看、当前打开，自动归类。
[00:17.5] 工作区也能钉上去，点开就是一整组。
[00:21.5] 收起来也不丢，它会回到该在的分组。
[00:25.5] 滚动、开关、随时撤销。
[00:31.0] dsh-pinned-sessions。
[00:34.5] 该在顶上的，永远在顶上。
```

### 4. 音效与音乐

1. 0-8 秒：只有低频心跳（约 60 BPM）与轻微环境底噪，弦乐不进场，制造压迫感。
2. 8.0 秒：点击瞬间给一个短促上扬音，弦乐低音铺底进场。
3. 12-25 秒：电子脉冲按 120 BPM 走，每段落一个轻点，与画面切换同拍。
4. 31 秒：电子层退场，只留弦乐与一次心跳，落在最后一句旁白之后半拍收尾。
5. 全片响度目标 -14 LUFS，旁白始终高于音乐 6 dB。

### 5. 字幕表（中英对照）

1. 27 个会话，3 个在跑 / 27 sessions, 3 running
2. 正在跑的，被挤到了下面 / The running one got pushed down
3. 点一下，它就在最上面 / One click, it is on top
4. 运行中、待查看、刚点开的，一屏看全 / Running, unread, open now — all in one view
5. 整个工作区也能钉上去 / Pin a whole workspace too
6. 收起来也不丢 / Folded away, never lost
7. 滚动、开关、随时撤销 / Scroll, toggle, undo anytime
8. 该在顶上的，永远在顶上 / Never lose the session that matters

### 6. 录屏操作清单

1. 环境：桌面端 1920×1080，界面缩放 100%，只留本插件与必要面板；准备 3 个工作区、12 条以上会话，其中 2 条正在运行、1 条跑完未点开。
2. 录制：60fps 无损，鼠标移动用平滑轨迹，每次点击前停顿 0.3 秒，避免画面抖动。
3. 必拍动作：滚动列表；会话「...」→ 全局置顶；工作区「...」→ 全局置顶；点小箭头折叠；点开会话；取消置顶；设置里开关一次。
4. 每条动作单独录一遍，方便剪辑时按时间码裁切。

### 7. 不用视频模型怎么做电影感

1. 抠出侧栏：把侧栏单独抠成圆角卡片，放到深色渐变背景上，加 12% 投影与 3% 噪点。
2. 遮罩转场：转场用同形状遮罩扩张，时长 0.25-0.4 秒，配合一点运动模糊。
3. 速度曲线：关键点击 0.35x，扫视 1.6x，其余保持 1x；速度切换点放在音效上。
4. 微距：把 200% 放大的圆点做成画中画，呼吸动画 1.4 秒一循环。
5. 打光：结尾一镜给侧栏加一条斜向高光扫过，配合弦乐起音。
6. 配音与字幕：TTS 出年轻女声，按旁白时间码对齐；字幕中英双行，字号 28/16，底部留 12% 安全区。

### 8. 验收清单

1. 每一句口播都能对上画面里的具体动作，没有一句"空口播"。
2. 每个功能点都能在事实底线里找到对应条目，没有虚构。
3. 三次呼吸的节奏点在音轨上可见：0-8 秒、8-30 秒、30-40 秒。
4. 字幕与口播逐字一致，英文字幕不断行。
5. 全片没有真人出镜与人脸。
